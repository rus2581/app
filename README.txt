NETWORK GUARDIAN (только Android)
1. Откройте папку android в Android Studio, дождитесь синхронизации Gradle.
2. Build > Build APK(s), установите APK на телефон.
3. В приложении впишите адреса (по строке: Название=адрес), интервал, таймаут ping, число неудач до тревоги, повтор голоса. Нажмите "Сохранить" и "Запустить мониторинг".
4. Настройки телефона > Приложения > Network Guardian > Батарея > "Без ограничений".
Все параметры можно менять в любой момент.
